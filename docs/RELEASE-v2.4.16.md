# v2.4.16 · Harness 0.2.2-rc.2 兼容更新

- 适配 rc.2 的侧栏滚动结构。色条从顶端开始，新会话、插件和自动化三颗按钮回到首根色条旁；原生插件导航可在底部 MORE 中使用。
- 顶栏提供调色盘和工作区样式切换，首页标题和输入框沿同一左缘排列。宽屏下字标留在顶栏内。
- Windows 可选竖排按钮适配器支持经过 SHA-256 核对的 rc.2 原始安装，安装时保留可恢复的备份。

将 `dsh-industrial-acid-skin-2.4.16.tgz` 导入 Harness 插件管理器。需要 Windows 竖排按钮时，另外解压 `dsh-industrial-caption-adapter-2.4.16.zip` 并按其中的 README 操作。两个文件的 SHA-256 均列在 `SHA256SUMS.txt`。

# v3.2.0 · 点阵动态

3.1 把界面收成石墨灰之后，画面稳了，但有点静。3.2 加了一层点阵动态：对话区的点阵跟着发送、输出和完成亮起，HUD 多了一个输出速率表，工作区编号切换改成 LED 翻牌，并配合四色遮罩一起走。所有动态都只在真实事件发生时出现，不做常驻的装饰动画。

## 对话区点阵

对话区的「+」格线下面多了一层很淡的点阵，平时几乎看不见，只在三种时刻亮起：

- **发送**：在输入框按 Enter（Shift+Enter 换行和输入法选字不算）或点发送键时，从输入框扩散一圈点阵波纹。
- **输出**：回复文字到达时，点阵在写字的位置附近留下一道渐暗的拖尾。
- **完成**：运行中的会话减少时（某个会话跑完），一条扫描带从上往下扫过。

## 输出速率表

顶栏 HUD 的「TOKENS · TODAY」旁边多了一个 24 × 5 的点阵表，按每秒到达的字符数亮起，用对数刻度：涓涓细流也看得出来，接近每秒 600 字时满格。没有输出时熄灭。

## LED 编号翻牌

切换工作区时，大号码 003 → 004 不再是扫描校准，而是 LED 点阵翻牌：旧数字碎成点、扫描线带着新颜色刷过、新数字一行一行点亮，最后点阵长大并合成为真实字形。结束时直接交还原本的文字，不会再跳一下。

同一段时间里，顶栏左侧其他内容也跟着变：

- **名称与路径**：先显示为随机字符，再从左到右解码成新的名称和路径。
- **当前工作区标签**：「✓ ACTIVE WORKSPACE」在开头反转一次，像盖章。
- **工作区符号**：符号的零件以打乱的顺序逐个出现，最后一条扫描带扫过。

## 遮罩的四个面

工作区切换时的四色遮罩，每一列都放了内容，与 LED 翻牌配合：

- **编号**：放大到填满遮罩列的 LED 数字，先乱跳再锁定。
- **名称**：工作区代号与名称一词一行，用 Acid Cipher 未知文字解码成正常文字。
- **条码**：放大的条码。
- **符号**：按整数倍放大到贴合最右一列，四角有准星框和 LOCK 标签，再扫过一条扫描带。

## 动效档位

- **完整**：以上全部。
- **克制**：保留速率表和编号翻牌，关闭对话区点阵。
- **停止**：全部停用，也跟随系统的“减少动态效果”。

点阵动态只在 Marathon 外观下运行，不改动 Harness 自己的节点；停用插件时清除所有画布、监听和临时节点。

## 兼容

- 支持 Harness `0.2.0-rc.2` 至 `0.2.1`（含 RC）、`0.2.2-rc.1`、`rc.2`、`rc.3`、`rc.5`，与 3.1.0 相同。
- 从 3.1.0、3.0.0 或 2.x 升级会保留工作区编号、颜色、侧栏样式、动效档位与用量界限。
- 在真实 0.2.2-rc.5 宿主归档上通过全部 137 项自动测试；动效在正式构建上做了行为检查（结束后遮罩、克隆节点和临时样式全部清空，停用后无残留，无脚本错误）。

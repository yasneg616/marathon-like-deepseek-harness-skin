# v3.0.0 · 每个工作区都有自己的颜色和符号

大版本更新。整套皮肤改由当前工作区决定颜色，工作区多了符号和状态，顶栏、遮罩、配色和底部抽屉都重新设计。

## 颜色与工作区

- 整套皮肤取当前工作区的颜色；其他工作区平时灰色待选，悬停只点亮那一条，不会把整个界面染过去。
- 运行中或等你回应的工作区亮出自己的颜色。
- 每个工作区自动分到一种符号（像素图腾、对位记号、资料标签、警示贴纸），会话状态直接演在符号上：运行中、等你回应、完成未查看。
- 侧栏可以收成 18px 细色线（Ctrl+B 或第四个指令键），收起与展开连贯折叠；悬停名牌带符号与状态。

## 顶栏、遮罩、配色、抽屉

- HUD 顶栏：96px，单色海报板（字标、出血大号码、名称路径、工作区符号）＋ HUD（会话数、运行中、等待中、今日 token）＋ OPS 状态墙。
- 印刷板遮罩：四栏改为同一工作区色的四种版面；切换工作区 4 栏、页面与侧栏面板 3 栏、对话框 2 栏、菜单 1 栏；遮罩落下后继续往下走。按钮悬停只留给关键按键，按下改为一次闪白。
- 01 配色系统：工作区色票（霓虹 / 工业 / 极地三组色票、全部工作区一起改色）、阅读画布、互动色与待机色（原酸性色）、跟随 / 固定开关。
- SYS 抽屉：左下角 MORE 改为安静的把手和今日用量三格表，只有超过最高界限或统计断线时显示警示斜纹；调色盘捷径移到 01 配色系统。

## 兼容

- 支持 Harness `0.2.0-rc.2` 至 `0.2.1`（含 RC）、`0.2.2-rc.1`、`rc.2`、`rc.3`、`rc.5`。
- 从 2.x 升级会保留工作区编号、颜色、侧栏样式、动效档位与用量界限。动效设为「停止」或系统要求减少动态效果时，遮罩与符号动画都不播放。

将 `dsh-industrial-acid-skin-3.0.0.tgz` 导入 Harness 插件管理器即可。

# v3.1.0 · Marathon 化

整套界面照着 Marathon 游戏内菜单的做法重新整理：骨架改成石墨灰，颜色只当信号用；空白处有填料；选中改为黑白反转；状态、计数和编号都变成小标签。二级菜单和 01 配色系统一起重做。Windows 原生窗口按钮不再需要适配器，Harness 更新也不会把它洗掉。

## 颜色只当信号

- 顶栏改为石墨灰。当前工作区的颜色只留在：编号区的淡色底、左侧 4px 色带、工作区符号和「✓ ACTIVE WORKSPACE」标签。
- 大号码 003 移到编号区的垂直中心，不再沉到底部被切掉。
- 侧栏只有当前工作区是整片饱和色；有状态的其他工作区是石墨卡片，加淡色、顶部色带和彩色符号；没有状态的维持灰色。
- 色条编号改成白底黑字的价格标签，当前工作区的标签反转为黑底白字。

## 空白处有填料

- 对话区铺一层很淡的「+」准星格线，首页和对话中都有。
- 侧栏底部铺斜线网纹，色条像插在架子上的卡片。

## 选中与标签

- 发送键是白底黑字的反转块；「配色 / 工作区」悬停和展开时反转。
- 运行状态（NEEDS YOU / RUNNING / DONE）改为小标签，需要处理的那个用该工作区的颜色。
- 输入框下方的模型与推理档位改为小圆角标签。

## 二级菜单

所有二级界面共用一套写法，照游戏的物品浮窗：顶部色带（工作区相关用工作区色，系统类用白色）＋大字标题＋小标签；中段深色说明；列表为「方形状态点 · 名称 · 右侧数值」，悬停反转；底部较暗的一条放次要操作。

- 工作区悬浮卡：工作区色标头、反转编号、「+ NEW CHAT HERE」标签，会话状态改为方形状态点。
- 对话框：白色标头与大字标题，关闭键为黑色方块。
- 01 配色系统：A / B / C 分区标签与大字标题；色票组改为卡片，选中整张反转；工作区列表如同物品清单；对比度改为数据格。
- SYS 抽屉、「更多」等原生菜单与色线提示同样改写。

## Windows 窗口

- **原生窗口按钮**：没有安装标题栏适配器时，Harness 自己的最小化 / 最大化 / 关闭会叠在「配色 / 工作区」上（3.0.0 的问题）。3.1.0 在顶栏右上角让出位置，三个按钮使用当前工作区的颜色，切换工作区时跟着变。全部由皮肤完成，不修改 `app.asar`，Harness 更新后依然有效。
- **直角窗口**：Windows 11 默认圆角。皮肤通过窗口图标所用的同一个可撤销助手把窗口设为直角，停用插件时恢复系统圆角。可用 `squareCorners: false` 关闭。
- 标题栏适配器（竖排按钮）仍可选用，不再是必需。

## 鲸跃彩蛋

在 Harness 首页空白处点击，鲸鱼会跃出水面，其中一种画法由代码文字组成。皮肤把这些代码换成原创的像素未知文字「Acid Cipher」，并使用当前工作区的颜色。字体由 `tools/cipher-font.cjs` 生成，随运行包内置。

## 兼容

- 支持 Harness `0.2.0-rc.2` 至 `0.2.1`（含 RC）、`0.2.2-rc.1`、`rc.2`、`rc.3`、`rc.5`，与 3.0.0 相同。
- 从 3.0.0 或 2.x 升级会保留工作区编号、颜色、侧栏样式、动效档位与用量界限。
- 在真实 0.2.2-rc.5 宿主归档上通过全部 131 项自动测试；在 Windows 实机确认原生按钮配色、对话区格线，以及直角窗口所用的 DWM 设置。

将 `dsh-industrial-acid-skin-3.1.0.tgz` 导入 Harness 插件管理器即可。
